# ЛР №18 — Тестирование Python-приложения (pytest, unittest.mock)

**Вариант 10. Железнодорожные билеты**: создание маршрута (рейса), продажа билета, возврат, наличие мест, поиск рейсов.

```
src/main.py (CLI)  →  src/services/ticket_service.py  →  src/repositories/sqlite_repository.py  →  SQLite
```

## Запуск
```bash
pip install -r requirements.txt
python -m src.main                                    # консольный интерфейс
python -m pytest -v                                   # 36 тестов
python -m pytest --cov=src --cov-report=term-missing  # покрытие
python -m pytest -m integration                       # только интеграционные
```

## Бизнес-правила (сервисный слой)
* рейс: номер обязателен, города различаются и не пустые, мест 1…1000, цена > 0, отправление в будущем, без дублей;
* продажа: пассажир указан, поезд ещё не ушёл, место в диапазоне и свободно; без номера — первое свободное;
  после продажи — уведомление пассажиру;
* возврат: ≥ 24 ч до отправления — 90 %, меньше — 50 %, после отправления — нельзя; повторный возврат запрещён.

## Стратегия тестирования
| Набор | Файл | Кол-во | Что проверяет |
|---|---|---|---|
| Unit (Mock Repository/Notifier, patch времени) | `tests/unit/test_routes.py` | 15 | создание рейса, валидация и границы (0, 1, 1000, 1001, пустая строка), дубли, поиск, места |
| Unit | `tests/unit/test_tickets.py` | 18 | продажа, занятое место, нет мест, границы номера места, возврат 90 % / 50 % / запрет, повторный возврат |
| Integration (настоящая SQLite) | `tests/integration/test_sqlite.py` | 3 | полный цикл продажи/возврата/перепродажи, поиск по городу и дате, уникальный индекс места |

* **Mock**: `Mock(spec=RouteRepository)`, `Mock(spec=TicketRepository)`, `Mock()` для уведомлений; проверки
  `assert_called_once()`, `assert_called_once_with(...)`, `assert_not_called()`, `call_args`.
* **patch**: `patch("src.services.ticket_service.now", ...)` — время подменяется там, где оно используется.
* **Параметризация**: 4 теста (`test_create_route_validation`, `test_create_route_boundary_seats`,
  `test_seat_out_of_range`, `test_refund_share_rules`).
* **Фикстуры**: `conftest.py` — маршрут, билет, моки, сервис, фиксированное время. Все тесты по схеме Arrange–Act–Assert.

и переход на летнее время при расчёте «за 24 часа».

## Найденная тестами ошибка
Интеграционный тест `test_search_by_city_and_date` упал: поиск «москва → санкт-петербург» ничего не находил.
Причина — встроенная функция `lower()` в SQLite не изменяет регистр кириллицы. Исправление: в `connect()`
регистрируется Python-функция `lower`. В unit-тестах с Mock-репозиторием эта ошибка была невидима — поэтому нужны
и интеграционные тесты.
